## Overview

- [Bun](https://bun.sh/) - A fast all-in-one JavaScript runtime.
- [Elysia](https://elysiajs.com/) - A lightweight and high-performance web framework for building APIs with Bun.
- [Next.js](https://nextjs.org/) - A React framework for building server-side rendered and static web applications.
- [Drizzle ORM](https://drizzle.team/) - A type-safe ORM for TypeScript and JavaScript.
- [PostgreSQL](https://www.postgresql.org/) - A powerful, open source object-relational database system.
- [Tailwind CSS](https://tailwindcss.com/) - A utility-first CSS framework for rapidly building custom user interfaces.

## Usage

```bash
git clone httpsL//github.com/eroxl/bend-stack-template.git
cd bend-stack-template  
```

```bash
cp .env.example .env
```

```bash
bun run dev
```
